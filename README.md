# gate-testbed

**禾赛 landing Capstone（门禁系统）的试验田仓库。不是真项目，别当代码看。**

## 这个仓库是干什么的

用来给本地的门禁服务（`hesai-gate/gate-server`）制造**真实的 GitHub 事件**：

- 提 PR → 触发 `pull_request` webhook → 门禁收到事件
- D4 会在这里**故意提一个有问题的 PR**，验证"合并按钮真的会变灰"

## 为什么单独建一个仓库

门禁要测的东西都很"破坏性"——**设分支保护、故意提坏 PR、把 required check 设成永远失败**。
这些操作**不能污染真项目**，所以单开一个。

## `src/index.ts` 里为什么有低级错误

**是故意的。** 那个文件留了两个 lint 问题，D5 要用它们验证「门禁能不能真的把有问题的代码挑出来」。

**修掉它们 = 把试验田犁了，D5 就没素材了。** 先别修。
